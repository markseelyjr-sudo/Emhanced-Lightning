# Thunder and Enhanced Lightning

A storm-powered block breaker. Made for you by Mark ♥

Play it in any browser on a phone (turn it sideways), a computer, or with a game controller.

- **Move:** mouse, touch-drag, A/D or arrow keys, or a gamepad
- **Launch:** Space, click, tap or A
- **Thunderstrike:** E, tap the storm meter, or B
- **Pause / difficulty:** P or the pause button
